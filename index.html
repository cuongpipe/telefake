Cấu hình Firebase Realtime Database REST API

Sử dụng JavaScript fetch() thuần, không cần SDK

Đường dẫn Firebase Realtime Database của bạn. API sẽ gọi trực tiếp đến {FIREBASE_DB_URL}/messages.json.

🛡️ Mẫu Firebase RTDB Rules (Cho phép đọc/ghi qua REST API): 
{
  "rules": {
    ".read": true,
    ".write": true
  }
}

Dán đoạn quy tắc trên vào tab Rules của Firebase Realtime Database trong Firebase Console để cho phép REST API đọc và ghi dữ liệu.
